# FareOrbit — landing page

The public landing page for FareOrbit, a flight search and fare-alert app
in development.

One static file, `index.html`, with no dependencies and no build step.
Published with GitHub Pages.

The app's own source lives in a separate, private repository.

## Keeping it honest

This page states that FareOrbit is unreleased and that its fares are currently
demo data. **Update it as that changes.** A page claiming a working product
while the app still shows synthetic prices would contradict what the app
itself tells its users.
